PISA Analysis Scripts (2000–2022)

This repository contains all Python scripts used in the analysis for an MSc dissertation exploring reading from a range of lenses: Economics, Psychology, Neuroscience and Philosophy. All data related to these scripts can be accessed and used via the OECD website: https://www.oecd.org/en/about/programmes/pisa/pisa-data.html

The cleaning scripts can be used for each individual student data response matrix. Scripts are tailored to each year. The regressions scripts can be used once the data has been cleaned.
